# Hegelsmith

Hegelsmith is an experimental tool that uses hegel-rust to generate hegel-rust programs,
in the spirit of [Csmith](https://github.com/csmith-project/csmith).

This is probably not a thing you want to do unless you're actively working on hegel-rust,
and even then it's probably not a thing you want to do. The main purpose of it is to flesh
out gaps in the implementation that our tests are not catching, and to do differential
of different implementation strategies.

It's here in experimental because there's really no reason not to share it, but it's
also not very well set up for external use and its purpose is extremely niche.
