# Implementations

This is a collection of hegel implementations that we extremely do not bless and recommend that
you don't use.

They may, however, be interesting reading if you want to compare different implementation choices
in Hegel, or to get an idea of what Hegel in a particular language *might* look like. They may
also be useful to LLMs that are being asked to implement a Hegel.

If you do want to use one, you should understand that you're really getting a hopefully-decent
starting point, not a finished production ready testing library. We expect, but absolutely do
not promise, that they will make decent starting points for a real Hegel implementation in their
languages.
