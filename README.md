# Experimental Hegel Code

> [!IMPORTANT]
>
> If you're looking for high quality production code, you've taken a wrong turning, this is not
> the place you want to be.
> 
> This repository is full of code that we think is better to make available than not, but you should
> not use it without due care and diligence, and we have no intention of supporting it at this time.
> You are welcome to report issues with us anyway, and please talk to us about it if there's any of
> it you want to use seriously, but we genuinely make no guarantees that we will support anything in
> here or do anything with your feedback.

`experimental` is a repository for things that we think are interesting enough to be worth sharing,
but that we don't actually particularly recommend people use. In particular it contains a lot of
hegel client libraries of various degrees of quality that we don't currently intend to support,
primarily ones which have been produced in the course of testing out our agent harness for developing
new Hegel implementations.

We expect most of these probably work tolerably well, but that they may contain some fairly major
flaws that we don't know about because we've barely looked and certainly haven't given the level of
human review and oversight that we would want to give anything we blessed as an official implementation.

Some of these libraries may be promoted to officially blessed implementations in the future, but it's
equally likely that if we decide we want to support one of the languages in here then we will redo it
entirely from scratch with a more mature agent harness and more human oversight at each step of the
way.
